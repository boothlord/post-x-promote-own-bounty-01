An X post promoting make.fun's new make-your-own-bounty feature: it links make.fun's announcement post, carries its own photo of the make.fun ghost posting a bounty, and asks readers what they would put a bounty on. The program copies POST.json, which names the post, into the output directory for the house to read back from X.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
